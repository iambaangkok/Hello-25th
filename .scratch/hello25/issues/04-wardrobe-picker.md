# Pick the 12 Months' colours and Outfits in a Wardrobe picker

Type: task
Status: open
Blocked by: 03

## Question

Build the Wardrobe picker on top of the Figure from the Figure prototype: flip through the 12 Months
(November → October); per Month an HSL picker for the background and for each Outfit part; option
choices for inner / outer / bottom (length, leg width) / shoes / bag; hair colour (defaults to the
same all year). Autosaves to localStorage; export/import JSON. Draft palette pre-filled. The human
picks everything and hands back the Wardrobe JSON. Resolved when the Wardrobe JSON is committed.
